<h1>Caçambex</h1>
<p>
Este projeto é um bot de atendimento via WhatsApp desenvolvido para automatizar e agilizar o gerenciamento de pedidos de aluguéis de máquinas e caçambas estacionárias.
O sistema utiliza a Evolution API e um webhook para envio e recebimento de mensagens, integrando toda a comunicação do cliente com um backend em NestJS.

Além disso, o bot se conecta ao Google Planilhas para consulta de dados, atuando como uma solução prática e acessível para empresas que desejam centralizar suas informações sem a necessidade de um banco de dados complexo.
</p>

<p>
  Principais funcionalidades

 - Atendimento automatizado via WhatsApp (mensagens, fluxos e respostas dinâmicas).
 - Integração direta com EvolutionAPI para envio, recebimento e processamento de mensagens.
 - Webhook para processamento de eventos e sincronização em tempo real.
 - Consulta de informações em Google Sheets (disponibilidade, preços, pedidos, etc.).
 - Backend em NestJS, modular e escalável.
 - Registro de interações e comportamentos do usuário.
 - Suporte a fluxos de atendimento como: Solicitação de aluguel de caçamba, Consulta de valores, Informações de endereço, Acompanhamento do pedido.
</p>

<p>
  Arquitetura do Projeto
  
 - Mensageria: EvolutionAPI (WhatsApp)
 - Webhook: Recebimento de mensagens e eventos
 - Backend: NestJS (TypeScript)
 - Integração externa: Google Sheets API
 - Hospedagem (opcional): Docker
</p>

<p>
  Objetivo

Fornecer uma solução automatizada e acessível para empresas de locação de máquinas e caçambas, simplificando o atendimento ao cliente e eliminando processos manuais repetitivos.
O bot oferece agilidade, redução de retrabalho e melhora significativa na experiência do usuário.
</p>
